# PRML 作业二：3D Make-Moons 分类实验讨论分析

## 2. 算法性能分析与讨论

### 2.1 为什么 Linear SVM 表现最差？
Linear SVM 在本实验中的准确率仅约 70%。这是因为 **Make-Moons 3D 数据集是典型的非线性可分数据**。
- 数据在 3D 空间中呈现出两个交织的半弧形（moons），且伴随有一定的噪声（noise=0.2）。
- 线性核尝试在原始 3D 空间寻找一个超平面对其进行拆分，但这在几何上是不可能的，导致大量处于“交错地带”的样本被误分类。

### 2.2 为什么 RBF 核 SVM 表现极佳？
RBF（高斯）核 SVM 达到了 98.8% 的准确率。其核心优势在于：
- **核技巧（Kernel Trick）**：RBF 核通过无穷维映射，将数据映射到特征空间，使得在原始空间中高度非线性的边界在新的空间中变得线性可分。
- **局部性特征**：RBF 核本质上是一种相似度度量（衡量样本间的欧氏距离）。对于 Make-Moons 这种局部空间聚集的流形数据，RBF 核能非常精准地捕捉到这种局部结构。

### 2.3 为什么 AdaBoost 表现最强？
AdaBoost 以 99% 的准确率位居第一。这得益于其集成的特性：
- **迭代纠错**：AdaBoost 通过一系列弱分类器（本实验中为深度为3的决策树）的组合，每一轮迭代都会增加对前一轮分类错误样本的权重。在这个 3D 数据集中，边界处的样本会被后续的弱分类器重点关注。
- **构建复杂边界**：虽然单个决策树的边界是阶梯状的，但多个决策树加权组合后，可以逼近极其复杂的非线性曲面，从而完美契合 Make-Moons 的几何形状。

### 2.4 决策树（DT）的表现分析
单一决策树的准确率为 95.4%。虽然表现不错，但由于数据集存在 0.2 的噪声，未剪枝的深度决策树容易过拟合到噪声点上，导致其在测试集上的泛化能力略逊于集成模型和具有正则化特性的 SVM。

## 结论
对于具有非线性流形特征（如 3D Make-Moons）的 PRML 任务，**RBF SVM** 和 **AdaBoost** 是最合理的选择，因为它们分别通过“空间变换”和“组合集成”有效地处理了复杂的判定边界。
